# 戌無营造 · 封面设计

原 Windows 封面设计工具的浏览器版本。React + Fabric.js，纯静态部署到 GitHub Pages。

## 功能

- 添加多张本机图片，每张保留自己的文字层；支持拖动、旋转、缩放、双击编辑。
- 文字不会随画布边界自动换行，手动回车会保留。
- 保留六套原有文字版式，新增十套小红书文字模板：大字描边、荧光重点、数字清单、杂志大刊、留白氛围、双栏对比、提问悬念、便签干货、胶片日记、贴纸批注。默认展示“小红书”分类，其他模板可在“全部”中选择。
- 新模板采用 3:4 基准版式，套用时沿用当前画布尺寸和背景图片；双栏对比是可编辑的文字标注，不会自动拼接两张图片。标题、字体粗细、底色、描边和位置均可调整。
- Noto Sans SC / Noto Serif SC 可变字体（100–900），以及系统字体、字体文件导入和收藏。
- 保留原版 20 个色卡并补充黑白灰；支持色盘、ARGB 色值、透明度、描边、阴影和可开关的文字底色。
- 文字/完整模板的保存、重命名、删除、JSON 导入导出；兼容原桌面版 Version 1 JSON 文字层。
- PNG / JPG / WebP 原始尺寸导出；当前文字版式批量套用到图片列表并下载 ZIP。
- 撤销、重做、画布居中、浏览器本地自动保存、手机面板切换。

## 本地运行

```sh
npm ci
npm run dev -- --port 5178
npm test
npm run build
```

## 数据与字体

图片、导入字体和自定义模板仅存于当前浏览器 IndexedDB，不上传服务器。清除网站数据会清除本地作品；模板可导出备份。不同设备或浏览器之间不会自动同步。

浏览器导出采用下载方式，不直接写入桌面版的保存目录。批量导出会将当前选中图片的文字版式应用到全部图片。最大输出边长为 4096 像素。

字体文件随网站托管，无需访问 Google Fonts CDN。Noto Sans SC / Noto Serif SC 采用 SIL Open Font License 1.1，许可证保存在 `public/licenses/`。示例建筑图片为生成的演示素材。

读取完整系统字体列表依赖支持 Local Font Access API 的浏览器及用户授权。系统字体未安装时浏览器会替换字体；重新打开网页后，授权读取的本地字体可能需要重新读取。导入的静态字体只包含文件自身字形，其他粗细可能由浏览器合成；内置可变字体提供真实的粗细变化。

旧桌面模板中的 Windows 背景路径无法在浏览器直接读取，需要重新添加背景；不同排版引擎可能造成细微字宽和行高差异。网页导出的完整模板可包含背景图片，但不嵌入导入字体。

## 发布

`main` 分支推送触发 GitHub Actions，运行测试及构建，发布 `dist` 到 GitHub Pages。没有账号密钥、用户图片或桌面安装包被包含在仓库中。
